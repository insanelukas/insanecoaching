# media-build (temporary work branch)

Tooling for the quiz's game-style characters and personalised end scenes on insanecoaching.com.
Not part of the website: GitHub Pages serves the `main` branch only. This branch can be deleted when the clips are in `main`.

- `media/gen.py` builds the prompt plan (30 characters, 150 scenes).
- `media/ids.txt` records the generation job for each clip.
